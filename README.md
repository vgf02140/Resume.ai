# 📚 EstudaMais — Plataforma Completa de Estudos

Site voltado para estudantes com ferramentas que auxiliam nos estudos diários e na preparação para concursos e vestibulares.

## ✅ Funcionalidades

- 📄 **Processamento de PDF**: Envie um PDF e o sistema gera questões e resumos com base no conteúdo
- 📝 **Resumos automáticos**: Cria resumos de materiais extensos
- 📅 **Cronograma de Estudos**: Crie e gerencie seu plano de estudos
- ✅ **Simulados com correção imediata**: Resposta corrigida assim que marcada, com explicação do erro
- 📚 **Questões por Bancas**: Modelo CESBRASPE, FGV, CESPE e Vestibulares (ENEM, FUVEST, etc.)
- 📁 **Repositório de Materiais**: Espaço para armazenar e organizar apostilas e arquivos

## 🚀 Como Usar

1. Baixe o arquivo `index.html`
2. Abra com qualquer navegador
3. Pronto! Funciona 100% no navegador

## 🔧 Para Produção

O código já funciona com exemplos. Para gerar questões e resumos reais do conteúdo do PDF, conecte a uma API de IA como **Google Gemini** ou **OpenAI**.
